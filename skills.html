Технічний стек

Нижче — інструменти та скіли, які були задіяні на кожному етапі цього проекту, у хронологічному порядку.

Охоплюється вебскрапінг, etl pipeline, статистичний аналіз, та ml.

1. Скрапінг рейтингів FIDE

R · rvest · httr

Автоматизований збір щомісячних рейтинг-листів FIDE топ-100 з 1967 по 2024 рік. Парсинг HTML-сторінок через rvest, обхід пагінації, нормалізація імен гравців та дат.

2. Скрапінг ігор чемпіонатів світу

R · rvest · stringr

Збір PGN-файлів матчів чемпіонатів світу з 1886 по 2024 рік. Витяг метаданих партій (гравці, рік, результат, кількість ходів), очищення та структурування у табличний формат. Окрема обробка rapid/tiebreak партій для коректного виключення з аналізу класичних матчів.

python-chess · Stockfish

Локальний запуск Stockfish для аналізу кожної позиції у ~3 000 партіях чемпіонатів світу — близько 18 годин роботи скрипта. ACPL підраховувався окремо для білих і чорних без жодних зовнішніх API чи хмарних сервісів.

3. Збір даних Lichess та ETL

Python · HuggingFace Datasets · pandas

Потокове завантаження ~10-15 мільйонів партій з датасету Lichess/standard-chess-games через hugging face datasets, із streaming=True — без завантаження всього файлу в пам’ять. Стратифікована вибірка по діапазонах Elo, фільтри по часовому контролю, кількості ходів та наявності eval-тегів.

ETL pipeline · Apache Parquet

Побудова багатоетапного ETL: сирі PGN → фільтрування → табличний формат із потрібними метриками → навчальний датасет. Збереження результатів у Parquet для швидкого доступу. Окремі пайплайни для тренувальної вибірки та кураторської добірки партій для застосунку.

4. Feature engineering та ML

python-chess · регулярні вирази

Парсинг PGN: витяг [%eval] (оцінка позиції) та [%clk] (залишок часу), перебудова дошки хід за ходом. Написано власний standalone-модуль без залежності від зовнішніх сервісів — той самий код працює і в ETL, і в реальному часі у Streamlit-застосунку.

Feature engineering — 41 ознака

Три групи ознак: точність гри по фазах (ACPL у дебюті / міттельшпілі / ендшпілі), паттерни аматорів (рокіровки, ранні виходи ферзя, різкі просідання оцінки в дебюті), часові ознаки (середній час на хід, частка швидких ходів, час у критичних позиціях).

LightGBM · scikit-learn

Регресійна модель для передбачення середнього рейтингу Elo за однією партією. Ранній стоп на валідаційному MAE, підбір потрібних параметрів, порівняння результатів між трьома різними варіаціями.

5. Аналіз та візуалізація

R · tidyverse · ggplot2

Аналіз рейтингів FIDE з 1967 по 2024 рік та ACPL матчів ЧС з 1886 по 2024 рік. Часові ряди, порівняння по десятиліттях та епохах, ковзне середнє, scatter plot-и з підписами (ggrepel), кастомні палітри.

gt · статистичні тести

Форматовані таблиці описової статистики. Welch t-test та Cohen’s d для перевірки гіпотези про різницю точності гри між епохами.

6. Інтерактивний застосунок

Streamlit · python-chess

Інтерактивна гра “Guess the Elo”: користувач переглядає партію хід за ходом і вгадує рейтинг гравців — змагаючись проти ML-моделі. Двоколонковий layout, кнопкова навігація по ходах, відображення матеріальної переваги та залишку часу на годиннику, кешування через @st.cache_data.
